# Base 0.3.0

- 侧栏、视图标签：Cascadia Code / PingFang SC，13px；工具栏文字 12px。
- 当前表使用灰色底、600 字重与不占布局空间的标记；当前视图增加顶部细线。
- 网格、看板、Timeline / 甘特图：使用同款字体，保留原生字号、行列尺寸、任务条位置、状态色及条件填色。
- 右侧记录详情：标题 22px / 600，字段名 12px / 500，普通文字值 14px / 1.5。保留原生字段布局、编辑控件与面板宽度。

Canvas 适配范围：

```css
.garr-container-bitable .faster-dom-wrapper > .faster-view canvas
body.suite-bitable > canvas[faster="1"]
```

看板先向带标记的屏外分块画布绘制文字，再合成到可见视口，因此两类画布均需处理。无标记的其他画布保持原样。不修改 `measureText`；字体绘制结束或抛错后恢复状态。

0.2 本机已在 Chrome 的 Custom Style Script 安装并核对持久保存。实页验证了网格选择与编辑框开关、看板卡片字体、右侧记录详情、下一条记录切换、详情 / 历史页签，以及甘特图月 / 季刻度切换。测试没有改动记录、拖动卡片或更改排期。其他浏览器尚未同步此 Base 版本。

完整安装与停用方式见仓库根目录。全部字段类型、精确文本光标、仪表盘、导出与嵌入式 Base 尚未完整验证。
